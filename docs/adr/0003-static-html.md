# 0003 — Static HTML, no CDN

## Status

Accepted (2026-10-17).

## Context

The board has to be readable offline and safe to open from a cloned repo. A hosted dashboard needs accounts, which are design-only.

## Decision

`governance_board.report` writes one HTML file with inline CSS and inline SVG, plus Markdown and `summary.json`. No script sources, no external fonts, no network.

## Consequences

Charts are simple bars. There is no live refresh. Alert delivery is out of scope. The committed example is regenerated by the command in `docs/example-board/MEASURED.md`.
